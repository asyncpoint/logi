# logi v1.0.0-rc1 — Feature Complete Release Candidate

> **logi v1.0.0-rc1** is a fast, terminal-first log inspector featuring memory-bounded live tailing, multi-gigabyte static log browsing with parallel querying, multi-file and directory aggregation, native Docker/Kubernetes log stream ingestion, and hardened terminal safety.

---

### Milestone: Feature Complete

This release candidate marks **logi v1.0.0-rc1** as **feature complete**. All planned core features, command-line interfaces, configuration schemas, filter grammar, and keybindings are finalized and covered by semantic versioning guarantees as outlined in [docs/STABILITY.md](docs/STABILITY.md). This release candidate focuses on end-to-end validation, performance verification, and real-world testing prior to the final 1.0.0 release.

---

### Major Features

- **Blazing Fast Lazy Static Browsing & Parallel Query Engine**  
  Inspects multi-gigabyte static files instantly through offset-based lazy loading without loading files into RAM. Parallel workers evaluate queries across CPU cores while raw pre-filtering rejects non-matching chunks before parsing, delivering a 2.3–5× speedup.
- **Memory-Bounded Live Tailing**  
  Follows active logs (`-f`, `-n <lines>`) across rotations, copytruncate, and truncations with strict memory bounds for long-running monitoring.
- **Multi-File & Directory Following**  
  Aggregates multiple log files or entire directory trees (`--dir-mode all`) into a unified chronological view with stable, per-file color-coded gutters and active file headers.
- **Native Docker & Kubernetes Stream Ingestion**  
  Reads piped standard input (`docker compose logs -f | logi`, `kubectl logs -f ... | logi`) while maintaining full interactive keyboard and mouse navigation. Automatically strips transport decorations, preserves per-service coloring, and keeps interleaved stack traces framed by source.
- **Format Parsing & Structured Profiles**  
  Auto-detects and parses plain text, JSON Lines (RFC 8259), Zap, Pino, Logrus, Slog, Klog, CRI (`/var/log/pods`), and NCache logs. Includes a dedicated record detail overlay with pretty-printed JSON.
- **Log-Relative Time Windows & Query Filters**  
  Supports expressive filtering expressions (`severity:>=warn`, `thread=43`, `since:15m`, `until:14:30`) that measure durations against the log's own timestamps, enabling historical queries without requiring timezone coordination.
- **Interactive Keyboard-Driven TUI**  
  Features vim-style navigation, bookmarks, error/warning jumping, status bar severity counters (`C:`, `E:`, `W:`), column visibility controls (`X`), and in-table search match highlighting.
- **Terminal Safety & Defense-in-Depth**  
  Treats all log content as untrusted input: sanitizes C0/C1 control codes, ANSI injection sequences, and Unicode bidirectional overrides to protect the terminal emulator.
- **Synthetic Generator (`logigen`)**  
  Ships a companion load generator for reproducible benchmarking, fuzz testing, and pipeline evaluation.

---

### Refinements in 1.0.0-rc1

- **Static Severity Counters**: Added background parallel severity counting (`C:`, `E:`, `W:`) for static files matching live mode behavior.
- **Search Cancellation & Highlight Clearing**: Clearing the search query (`Ctrl+U`, `Ctrl+W`, or backspace) instantly cancels running scans and clears match highlights from the viewport.
- **OSC 52 Clipboard Copy**: Pressing `y` copies individual records or active selections directly to the system clipboard without ANSI styling artifacts.
- **Preserved Multiline Detail Layouts**: Retains original line breaks and indentation for exception frames and stack traces in the record detail overlay.
- **Architectural Isolation & Zero-Allocation Buffers**: Refactored session openers and configuration tables, resolved all `staticcheck` / `govulncheck` items, and eliminated per-flush buffer allocations on quiet tail streams.

### Quick Start
```bash
logi app.log                                  # Browse a large static file
logi -f /var/log/containers/                  # Follow directory rotation
docker compose logs -f | logi                 # Follow container stream with service colors
logi --since 30m --level warn,error app.log   # Query warn/error records in the last 30 minutes
```

Detailed task recipes and configuration options are available in [docs/HOWTO.md](docs/HOWTO.md) and [docs/config.example.yaml](docs/config.example.yaml).
